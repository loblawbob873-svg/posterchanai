# Reciprocal automatic mutes

User Settings → Muted now offers an opt-in **Auto-mute people who mute you**
switch and **Update now**. The account's enabled state, verified public-list
watermarks, automatic mute cache, manual exceptions, last successful check and
result counts persist in an account-scoped localStorage record. Reloads hydrate
filtering immediately, including offline. This state is local to this account
on this device; it is not a cross-device preference sync.

Checks discover public kind-10000 lists tagging this account, then fetch each
candidate's latest list without the `#p` filter so an unmute can be detected.
Signatures are checked in the existing crypto worker. Newer lists win, with
lowest event ID breaking equal-timestamp ties. Missing replies, incomplete
relay queries and failed durable writes retain the previous cache. Private
or encrypted mute entries cannot be detected. Discovery is bounded to 5,000
authors and reports a limited check when pagination cannot finish.

Automatic filtering is separate from manual NIP-51 mutes and does not publish
or ask the signer to rewrite the manual list. Turning it off removes automatic
filtering immediately. Explicitly unmuting an automatically muted account
persists an exception; confirmed public unmute ends that exception so a future
new public mute can be detected normally. Enabled sessions check every 15
minutes while visible; reload schedules an overdue check after 10 seconds.

Reconciliation updates inbox rows or keyed timeline cards without remounting
an active composer. Account changes and setting changes invalidate obsolete
pending checks. Other tabs hydrate saved changes through storage events.
