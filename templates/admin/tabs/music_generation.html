Music Generation (ACE-Step)

Songs are generated in-process, on this app's own torch stack and GPU lock — the same way video generation works. There is no acestep.service, no second virtualenv and no HTTP hop. Install the engine once with ./install.sh --music; the weights land in <ACESTEP_ROOT>/checkpoints and load on first use. Generation is available in the web UI and Telegram via musicgeni <style prompt> [| lyrics].

Output & Watermark

Each song is delivered as a branded video: the song plays over a generic PosterChan background, then the branded end-card outro (the same "watermark" used on effect videos) is appended.

When off, the song video has the background but no end-card.
