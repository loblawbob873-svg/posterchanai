Built-in Blossom Media Server
Serves Blossom (BUD-01/02/06) at /blossom on this app's port. Front it with TLS so clients use https://yourdomain/blossom. Blobs are public-by-hash; uploading requires the per-user 🌸 Blossom access toggle (Admin → Users) and a linked Nostr key.
Advertised in blob descriptors / list responses. Leave blank to derive from the request (set it if behind a reverse proxy that rewrites the host).
Storage
Proxy stores blobs on the shared PosterChanAI storage server (the same one configured under Services → Storage). Falls back to local automatically if no storage server is set.
Only used by the local backend. Blank = data/blossom under the app root (or $POSTERCHANAI_BLOSSOM_PATH).

Serves hot blobs from memory to save disk I/O / SSD wear and skip the cross-node storage fetch. LRU-evicted; blobs over 16 MB are never cached. 0 disables it.
Expiration
0 = blobs never expire. Otherwise each blob is deleted (bytes + record) this many days after upload; a background sweep runs every 10 minutes. Re-uploading a blob refreshes its window.
