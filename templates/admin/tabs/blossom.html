Built-in Blossom Media Server
The built-in Blossom media server is core and runs by default — it serves Blossom (BUD-01/02/06) at /blossom on this app's port. Front it with TLS so clients use https://yourdomain/blossom. Blobs are public-by-hash; uploading requires the per-user 🌸 Blossom access toggle (Admin → Users) and a linked Nostr key.
Advertised in blob descriptors / list responses. Leave blank to derive from the request (set it if behind a reverse proxy that rewrites the host).

Mirroring (disaster recovery)
Each newly-uploaded blob is copied to these Blossom servers (BUD-02), signed by this node's operator key, by a dedicated background worker that drains a queue one blob at a time (paced — never floods a mirror or blocks the upload). On by default, pre-filled with blossom.primal.net (verified to accept anonymous operator-signed uploads). Other public servers like blossom.nostr.build gate uploads behind an account and reject ours — only add one if your operator npub is registered there. A private mirror you control just needs the operator npub whitelisted; a server that rejects logs a skip. Blank = off. These URLs (plus this node's public Blossom URL) are auto-advertised in the operator's and each bot's kind-10063 server list, so clients fall back to them by hash when this node is down.
Expiration
0 = blobs never expire. Otherwise each blob is deleted (bytes + record) this many days after upload; a background sweep runs every 10 minutes. Re-uploading a blob refreshes its window.
