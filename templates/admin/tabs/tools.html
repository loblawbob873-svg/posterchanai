Calendar (CalDAV)
Serves this node's calendars over CalDAV at /caldav, so phones and desktop calendar apps can sync them. Nothing to install — it runs inside this app. Calendars are stored as encrypted Nostr events; each user generates a CalDAV-only app password in the client (Settings → Calendar) to add it to a device. Off by default, because turning it on opens a password login.
Calendar reminders need nothing here: an event's own alarm ("remind me 15 minutes before") becomes a reminder, which already reaches the web UI, a phone by push, and Telegram when it is linked.
Email notifications
Polls each user's IMAP INBOX and pushes new mail to their phone even when nothing is open. Without it, mail is fetched when the client opens or on login — fine at a desk, no use on a locked phone. Off by default: a background poll across every account on the node is real, recurring load, and this feature has been taken down by exactly that once before. Runs in the worker process, never the one serving pages.
Minimum 2, and the service enforces that floor whatever is typed here. 10 is a sensible default; shorter intervals mean an IMAP round trip per account, that often, forever.
SearXNG (Search)
Off = this node makes no search requests at all: the AI's web lookups, the news digests, the bots and Discover → Web Search all return nothing. (Clearing the URL below does NOT do this — it falls back to the bundled instance, then to a public one.)
Where this node searches — used by the AI's web search, the news digests, the bots and Discover → Web Search. Leave EMPTY to use the SearXNG bundled with this node (./install.sh --searxng, or the searxng compose profile), which is probed automatically; with neither, searches fall back to a public instance (https://searx.tiekoetter.com) that rate-limits servers. Requests to a remote instance go through this node's Tor proxy, falling back to direct.

Screenshot
Hosts the screenshot command may capture even if they resolve to a private/LAN IP — for your own domains that use split-horizon DNS (e.g. poster.place → a LAN address). Comma/space/newline-separated; a parent domain also covers its subdomains. Everything else is still blocked by the SSRF guard.
