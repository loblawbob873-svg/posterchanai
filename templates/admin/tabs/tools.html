SearXNG (Search)
Off = this node makes no search requests at all: the AI's web lookups, the news digests, the bots and Discover → Web Search all return nothing. (Clearing the URL below does NOT do this — it falls back to the bundled instance, then to a public one.)
Where this node searches — used by the AI's web search, the news digests, the bots and Discover → Web Search. Leave EMPTY to use the SearXNG bundled with this node (./install.sh --searxng, or the searxng compose profile), which is probed automatically; with neither, searches fall back to a public instance (https://searx.tiekoetter.com) that rate-limits servers. Requests to a remote instance go through this node's Tor proxy, falling back to direct.
