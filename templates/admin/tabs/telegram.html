Large files on Telegram (optional) The cloud Bot API caps bot downloads at 20 MB, so compress/convert only work on small files. A local telegram-bot-api server raises that to ~2 GB. Do these in order:
  1. Fill in API ID, API Hash and the Bot API server URL below, then click Save Settings.
  2. On the bot host (server1) run once: sudo ./scripts/setup-telegram-local-api.sh (builds & starts the server; ~10–20 min).
  3. Click Test Local Server and wait for the green “OK”.
  4. That unlocks Use local Bot API server — tick it, Save Settings, then Setup Webhook.
Keep it private — usually http://localhost:8081.
