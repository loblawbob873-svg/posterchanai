Video Generation (native diffusers — any text-to-video model)

Text-to-video runs natively in-process on this box's GPU (like image generation, not a separate server), so it shares the same GPU lock and VRAM model-swap: chat, image, music and video all queue as one GPU task at a time. Works on NVIDIA (CUDA), Intel Arc (XPU) and AMD (ROCm). Available in the web UI and Telegram via videogeni <prompt> [| negative]. Every knob below is yours to tune for your GPU — the defaults target a 12–16 GB card; with 24 GB+ you can run bigger models, higher resolution and longer clips (raise the model + frames + max-frames + resolution accordingly).

HF id or local path of any diffusers text-to-video model — the loader auto-detects the pipeline. The model auto-downloads on first use. Pick for your VRAM:
  • 12–16 GB: Wan-AI/Wan2.1-T2V-1.3B-Diffusers (~3s) or THUDM/CogVideoX-5b (~6s, better quality, needs offload)
  • 24 GB: THUDM/CogVideoX1.5-5B (10s, 768p) or higher-res Wan
  • 40 GB+: Wan-AI/Wan2.1-T2V-14B-Diffusers (true HD)
Stay on stock diffusers (Wan/LTX/CogVideoX) for Arc/ROCm portability — no fp8/GGUF.
