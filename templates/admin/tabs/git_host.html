🌿 Git Host (GRASP git-over-nostr)
Self-contained smart-HTTP git server (subprocess) with push authorized by maintainer-signed Nostr kind-30618 — no HTTP passwords. OFF by default; nothing spawns and /api/git 404s until enabled. See docs/GIT_OVER_NOSTR.md.
The git-http subprocess binds 127.0.0.1:<port>; reach it publicly via an nginx location /git/ → proxy_pass 127.0.0.1:3053.
Leave 127.0.0.1 (container turnkey may set 0.0.0.0).
Stamped into 30617 clone URLs, e.g. <base>/<npub>/<id>.git.
npubs allowed to create repos (one per line/comma). Empty ⇒ admins only.
Enforced in the pre-receive hook; a push over cap is rejected.
The daily reaper gc's repos and warns when total exceeds this.
A non-fast-forward is accepted only because a maintainer signed the new state; turn off to require fast-forward.
Convenience/automation path (e.g. sync.sh): a maintainer-signed NIP-98 header authorizes a push; post-receive derives the 30618.
Private repos require a NIP-98 read auth (allowlisted readers/maintainers) to clone and are NOT announced (no public 30617/30618).
When SET, this node runs NO local git subprocess — it forwards smart-HTTP git requests to the hosting node (like the Blossom storage proxy). Auth + repos + hooks stay on the hosting node. Empty ⇒ run the local host (per the enable toggle above).
