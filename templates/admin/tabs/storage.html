Set the same value on every node. Nodes forward work to each other (image/music/video/voice generation, torrents, remote storage) with no user session, and used to prove they were a node by setting a header any caller can set — so anyone could use those endpoints, and read other users' files, without an account. With a secret set, peers must prove it. Leave empty and the old header-only trust still applies, so filling this in on every node is what actually closes it.

ℹ️ Load-balanced storage

For load-balanced setups, set Storage Server URL to proxy file requests to a designated storage node. This avoids requiring a shared filesystem (NFS) — one node handles storage, the others proxy requests to it.

Setup:
• Storage node: leave storage_server_url empty, set upload_path to a local directory
• Client nodes: set storage_server_url to the storage node (e.g. 192.168.0.10)
