Voice Cloning (Chatterbox)

Zero-shot voice cloning: a few seconds of reference audio, then arbitrary text in that voice. It runs in-process on this app's own torch stack and GPU lock, the same as image, music and video — no sidecar and no second virtualenv. Install it once with ./install.sh --voice, then press Download below. Available in the web UI (AI Chat → Voices) and Telegram via voice <text> with a clip attached.

This is not the same thing as narration. The Text-to-Speech voice under Tools is edge-tts — Microsoft's cloud voices, instant and free of GPU. Cloning is a local model that holds this node's GPU for roughly 10× realtime (a 30s clip ≈ 5 minutes), during which chat, image, music and video all queue behind it. Leave it off unless you want that trade.
