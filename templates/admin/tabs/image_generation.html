VRAM Management
Shared: Single GPU - unload one model to load the other. Dedicated: Multiple GPUs or high VRAM - keep both loaded. LLM Only: Always use remote servers for image generation.

Shared Mode: When you generate an image, the LLM is unloaded first. When you chat, the image model is unloaded first. Best for single GPU with limited VRAM.

Dedicated Mode: Both models stay loaded at all times. Use this if you have multiple GPUs or sufficient VRAM (24GB+) for both models.

LLM Only Mode: This node only handles LLM requests. All image generation is forwarded to remote servers configured in Image Server URLs. Use this for dedicated LLM nodes in a multi-server setup.

Image Editing (regeni — auto-mask + SDXL inpaint)

Edit an uploaded image by text (regeni change the background to a beach, change her hair to red, change the eyes to green) — no manual mask: CLIPSeg turns the named region into a mask, then SDXL inpaint regenerates just that region. Reuses your geni SDXL models (base + anime — it picks the anime model when the instruction mentions/looks anime). Runs in-process on this box's GPU (shares the GPU lock + VRAM swap), ~8 GB, and is portable across CUDA, Intel XPU and AMD ROCm (no big LLM text encoder). Best at recolour / replace / remove within a region (background, hair, eyes, clothing, objects); not for big pose/structure changes. Available in web UI, Telegram, Matrix, Pleroma. Editing an uploaded photo is an abuse surface — keep it off unless you want it; the Pleroma path applies the CSAM/bad-word gate to the instruction.
