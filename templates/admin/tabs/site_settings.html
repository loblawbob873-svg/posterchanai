ℹ️ Load Balancing

For load-balanced setups, configure Storage Server URL to proxy file requests to a designated storage node. This avoids requiring shared filesystem (NFS) - one node handles storage, others proxy requests to it.

Setup:
• Storage node: Leave storage_server_url empty, set upload_path to local directory
• Client nodes: Set storage_server_url to storage node URL (e.g., http://192.168.0.10:3051)
