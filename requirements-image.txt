# Image-generation dependencies (Intel Arc / PyTorch XPU). Install into the image venv
# (venv-xpu-new) IN ADDITION to requirements.txt.
#
# MODERN STACK (2026-06): native PyTorch XPU - no IPEX needed for diffusers.
#   1) Install torch 2.8 XPU FIRST (it bundles its own oneAPI 2025.1 runtime via pip):
#        pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/xpu
#   2) Then this file.
#
# SYSTEM REQUIREMENT: Intel Graphics Compiler (IGC) >= 2.35.5 (run scripts/install-igc.sh).
#   - SDXL at >=768x768 FAILS on older IGC (2.23.0 / 2.35.2) with oneDNN
#     "could not create a primitive". IGC 2.35.5 fixes it (it is also what the LLM 14B needs,
#     so one IGC now serves BOTH GPU services - the old 2.23-vs-2.35 conflict is gone).
#   - 512x512 works on older IGC; 768/1024 need 2.35.5.
#
# transformers MUST be <5: transformers 5.x changed CLIPTextModel and breaks diffusers SDXL
#   ("'CLIPTextModel' object has no attribute 'text_model'").

diffusers>=0.38.0
transformers>=4.40.0,<5
accelerate>=0.28.0
safetensors>=0.4.0
pillow

#   it can drag in a mismatched torch). Examples:
#     XPU:  pip install torchvision --index-url https://download.pytorch.org/whl/xpu
#     CUDA: pip install torchvision --index-url https://download.pytorch.org/whl/cu130   (match cuXXX)
