# Nostr-only build (GPU=nostr): the relay + Nostr web client + Blossom + the non-AI app features
# (mail / news / torrents / file manager / TTS / social bridges). NO AI stack — no torch,
# llama-cpp-python, diffusers, transformers, and none of the heavy ML extras (faster-whisper,
# insightface, opencv, onnxruntime, rembg). Result: a small, fast image for people who just want
# a self-hosted Nostr relay + client. The app boots fine without the AI libs (all ML imports are
# lazy); AI commands/endpoints are hidden in nostr-only mode (POSTERCHANAI_NOSTR_ONLY=1).
#
# Keep this in sync with the non-AI deps in requirements.txt.
# Media Center works in this lean build too: httpx for NAS proxying, Pillow for
# covers, and cryptography/websockets for encrypted local catalogs. FFmpeg/ffprobe
# are installed by Docker or the host package manager; no torch stack is needed.
