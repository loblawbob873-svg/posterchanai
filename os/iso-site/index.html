Install or upgrade

From a USB stick to your desktop.

The same image installs fresh or upgrades an existing install. An upgrade keeps everyone's home folder and files.

  1. Download

    Get the ISO above and check its SHA-256.

  2. Write it to a USB stick

    Any image writer works: balenaEtcher, Rufus (DD mode) or dd.

  3. Boot it

    Try the live desktop first, or go straight to the installer.

  4. Install or upgrade

    Pick “Install PosterChanOS”, or “Upgrade an installed PosterChanOS” to keep your files.

sudo dd if=posterchanos.iso of=/dev/sdX bs=4M status=progress oflag=sync

Replace /dev/sdX with your USB stick. Everything on it is erased.
